# ASMR Concentric Rings Race: Cloud Video Generator

Automated 2D rigid-body physics simulation & ASMR marble race video renderer powered by Pymunk, Pillow, NumPy, FFmpeg, and GitHub Actions.

## Features
- **Format:** 1080x1920 (9:16 Vertical format for Reels/Shorts/TikTok)
- **Duration:** 92.0 Seconds (2,760 frames @ 30 FPS)
- **Physics Engine:** Pymunk 2D Rigid Body with continuous radial inward gravity and dynamic orbital swirl forces.
- **Visuals:** 7 Concentric spinning neon rings with rotating escape gaps leading to the Golden Center Core, surrounded by obsidian HUD and real-time live racer standings.
- **Audio:** 100% Real Recorded Tactile Glass/Ceramic Marble Clacks with spatial stereo panning and soft-saturation limiting.

## Cloud Rendering via GitHub Actions
Run this repository's GitHub Actions workflow to render the full 92-second video in ~60-90 seconds on GitHub's Ubuntu runners. The final MP4 is automatically uploaded to GitHub Releases.
